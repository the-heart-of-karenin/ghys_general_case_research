## 研究方向

尝试将复秩一情形推广至任意稳定、不稳定复秩，研究紧致复流形上全纯 Anosov 微分同胚的一般分类。当前采用的目标是复 infra-nil 模型：实单连通幂零 Lie 群上的左不变可积复结构、格商及其有限自由全纯仿射商，允许原映射为双曲全纯仿射自同构。不把该实 Lie 群预设为复 Lie 群，也不要求两侧分布全纯。模型范围的核验见 05、07、10。

既有复秩一独立推导位于 ../2/independent_research_20261017/，作为待独立复核的研究成果保留；推广工作不得将其中未经独立复核的步骤自动当作外部已知定理。
