# 一般全纯 Anosov 刚性：推广研究记录

建立日期：2026-10-17。

当前优先目标按用户最新指令收窄为：**无 pinching 的保全纯辛 Ghys 猜想，集中解决连续分布到 C1 或足够横向 holonomy 估计的入口**。暂不追求整个一般猜想，也不继续扩展任意实辛形式分支。

最新一轮记录：17 给出不预设 C1 的差紧致性二择；18 构造高阶集中反例，说明全部固定阶叶内 jet 横向光滑、任意接近 1 的双 Hölder 及保体积仍不足以推出 Lipschitz；19 完整证明平均 Dini 二阶差分的 C1 充分判据，并在六维共振模型和局部粗糙模型中检验。失败路线在 20，未解决任务在 21。**没有从原始假设推出 C1，没有紧致 Anosov 反例，也未确定最弱额外条件；无夹逼分类仍未证明。**

此前的条件性结果继续保留：准确实保辛归约（10）、全纯辛共振张量（11）、C1 后逐叶几何（12）、连续生成势（13）、已有保辛共轭升级（14）、法向差极限（15）、一般实辛形式下 C1 后的逐叶全纯线性化（16）。这些不作为本轮的 C1 输入。

此前已完成任意秩 Grassmann–Lp 正则化（04）、模型与共振核验（05）、周期非共振判据（06）、双 Lipschitz 接口核验（07），以及无需预设拓扑的保辛 pinching 分类（08）。上一阶段状态保留在 notes/09_results_and_frontier.md。

第一轮规划与检索记录保留在 notes/01–03。十六篇 PDF 在 literature/，来源与散列见 literature/sources_manifest.json。10–12 的适用范围审查见研究笔记 10 §5；13–14 支持叶内仿射与 special complex 几何背景；15 为 Journé 正则性引理；16 为 Zeghib 的几何横向正则性论文，其高余维及复运动页已渲染核验。原始文献与独立笔记仍分开存储。

## 研究方向

尝试将复秩一情形推广至任意稳定、不稳定复秩，研究紧致复流形上全纯 Anosov 微分同胚的一般分类。当前采用的目标是复 infra-nil 模型：实单连通幂零 Lie 群上的左不变可积复结构、格商及其有限自由全纯仿射商，允许原映射为双曲全纯仿射自同构。不把该实 Lie 群预设为复 Lie 群，也不要求两侧分布全纯。模型范围的核验见 05、07、10。

既有复秩一独立推导位于 ../2/independent_research_20261017/，作为待独立复核的研究成果保留；推广工作不得将其中未经独立复核的步骤自动当作外部已知定理。
