# 一般情形的证明规划

日期：2026-10-17。性质：研究路线和候选中间命题，不是一般猜想的证明。这里所有额外假设仅用于阶段性弱结果，不追加到最终目标。

## 目标及已知出口

目标：紧致连通复流形 X 上任意全纯 Anosov f，都双全纯共轭于带左不变可积复结构的实 infra-nilmanifold 的双曲仿射自同构。

目前最清楚的出口是 Zhang 2026 Corollary D：

\[
\boxed{\text{找到仿射 infra-nil 模型与双 Lipschitz 共轭}}
\Longrightarrow\boxed{\text{双全纯分类}}.
\]

这一出口允许两侧分布非全纯，符合已知例子。证明规划应尽量把新工作集中于模型的构造与共轭的度量正则性。

## 路线 A：先做环面拓扑模型，再撤去谱条件

优先级：最高，作为 L2 方法的第一个可控测试。

### A1. 第一个候选弱命题

暂假设：

1. X 同胚于实环面；
2. E^s 已全纯；
3. 某个迭代 F=f^m 满足下面的严格 L2 谱条件。

候选结论：E^u 全纯，然后应用 Zhang 2026 Theorem 1.2 得到复环面及双全纯线性共轭。

将复秩一笔记的仿射分裂丛推广到 N=TX/E^s 的任意秩。记

\[
S_x=DF_x|_{E^s_x},\qquad U_x=DF_x|_{E^u_x},
\]

取连续正交 Hermitian 度量，m 表示余范数。候选充分条件为

\[
\kappa_F:=
\sup_x
|\det_{\mathbb C}S_x|^2|\det_{\mathbb C}U_x|^2
\left(\frac{\|S_x\|}{m(U_x)m(S_x)}\right)^2
<1. \tag{A}
\]

理由仅作规划：分裂差向量丛 Hom(N,E^s) 的推送因子为 \|S\|/m(U)，完整反全纯余切因子至多 1/m(S)，换元带实 Jacobian。下一轮须完整验证范数选择、无维数常数的估计以及光滑逼近的分布极限。本轮不将此候选作为已发表或新获证明的定理。

先在复四维 (2,2) 的线性环面模型上检查 (A) 非空，再在已有非全纯 nil 模型上查明哪一项阻止严格收缩。

### A2. 去掉“已全纯的一侧”

尝试把仿射丛引理升级为全纯 Grassmann 丛上的非线性正则化。稳定/不稳定分布是该丛的连续不变截面；有望先在严格谱条件下得到全纯性，而不事先构造全纯商丛。

这一步需要新论证：图变换的邻域、非线性误差控制、光滑近似及完整反全纯导数的估计，不能只把商丛记号换一下。

### A3. 去掉谱条件，但暂保留环面拓扑

目标：X 同胚于实环面、f 全纯 Anosov，即推出 X 为复环面；不预设两侧全纯。

这是比一般猜想弱、又超出已检索 Theorem 1.2 假设的清楚目标。可能通过周期数据、环面模型上的复结构约束，或对拓扑共轭的双 Lipschitz 提升完成。

若单纯 L2 收缩失败，先识别非收缩/共振张量，不直接断言它们都应为零。先检查有限维共振障碍能否在环面拓扑下排除。

## 路线 B：允许非交换模型，用正规形取得双 Lipschitz 共轭

优先级：中高，是与一般猜想兼容的主要方向。

先暂假设 X 同胚于实 infra-nilmanifold，并在窄带谱、适度 pinching 或相应非共振条件下研究。

建议的阶段目标：

1. 取得适用的逐叶全纯/光滑正规形；优先选用原本就是全纯的 Berteloot–Dupont–Molino 版本，交叉核对 Kalinin–Sadovskaya 的叶上相干性。
2. 研究稳定和不稳定正规形之间的 holonomy 相容性，识别其有限阶转移结构。
3. 用正规形或周期数据证明 Franks–Manning 共轭沿两侧叶有统一双 Lipschitz 界，再验证局部乘积坐标是否足以推出全局双 Lipschitz。该最后拼接步骤并不自动成立。
4. 应用 Zhang Corollary D，完成这个带谱条件的弱版本。
5. 逐步允许多项式共振项，撤去 pinching；允许 torsion 和非零括号，避免错误地只留下环面。

这里不要求 E^s、E^u 为全纯子丛。只要求每片叶已有的复结构与所构造几何相容，并争取横向 C∞ 正则性。

主要缺口：单叶正规形并不给出横向正则性；周期导数数据是否受到 J 的可积性强约束，需要另立命题。

## 路线 C：有限阶不变几何结构，取得全局代数模型

优先级：长期主线；负责最终撤去“X 已有 infra-nil 拓扑”的假设。

尝试的链条：

\[
\text{全纯 Anosov}
\xrightarrow{\ ?\ }
\text{有限阶相容正规形/不变几何结构}
\xrightarrow{\ ?\ }
\begin{matrix}
E^s,E^u\text{ 为 }C^\infty,\\
\text{不变光滑实仿射连接及传递性}
\end{matrix}
\xrightarrow{\text{Benoist--Labourie}}
\text{光滑 infra-nil 仿射模型}.
\]

有了 C∞ 共轭，自动有双 Lipschitz 共轭，可接 Corollary D。

另一种实现：从稳定与不稳定正规形生成局部对称伪群，争取全局齐性、完整性、适当不连续的格作用，再识别幂零模型。

必须分开的实质问题：

- 怎样从复结构及动力学得到横向 C∞ 正则性；
- 如何拼出覆盖所有 TX 方向的不变实连接，而非仅逐叶连接；
- 怎样证明传递性/所需全局齐性；
- 有限维正规形群为什么最终产生幂零全局模型；
- 局部结构何以完整并可发展到万有覆盖。

有限维正规形群通常带线性半直积部分，不能直接视为幂零群。叶为 C^r 也不能自动给出全局乘积或 π1 虚幂零。

## 路线 D：复几何与附加结构的并行分支

### D1. Kähler/射影分支

从已知 Cantat 射影且两侧全纯的结果出发，研究能否削弱分布正则性，或把射影推广到 Kähler。可检查规范丛、特征类、正流及基本群约束是否迫使环面有限覆盖。

这条分支适合产出弱定理，但最终一般猜想包含非 Kähler nil 模型，不能把 Kähler 性当作最后必须推出的性质。

### D2. 一致拟共形与高秩作用

一致拟共形分类和无秩一因子高秩作用已有强结果。用它们作方法校验和已知终点，避免重新证明已知定理。

可探索复结构是否提供某种额外局部对称性，从而接近高秩刚性机制。但 J 的共循环相容关系不等于一个真实的、与 f 交换的第二个全局微分同胚；这一点不能偷换。

## L2 方法真正要推广的对象

一般情形已有 E^s、E^u 都非全纯的模型，所以不能把所有 \bar\partial 缺陷都压成零。

更合理的尝试：

1. 按动力学权重分解缺陷，先用 Lp/加权 L2 估计消去严格收缩部分；
2. 保留有限阶共振项，检查它们能否构成光滑张量及 nilpotent bracket 的结构常数；
3. 寻找带 torsion 的不变几何结构，或在有限 jet 丛中工作；
4. 若引入行列式线丛、外幂或权函数，须证明其全局存在及等变性，不能形式上抵消权重；
5. 对任何得到的中间结论，用已知非全纯的复六维 nil 模型测试，避免证明一个与例子矛盾的“过强结论”。

复秩一还用了两个特殊事实：商丛的 End 是标量，以及一维射影几何。高秩下曲率有矩阵共轭及 A∧A 项，不能照搬标量联络的平坦化。

## 建议的实际顺序

1. 精读、独立核对两个近期预印本的接口定理及非全纯模型，明确已知边界。
2. 在复四维 (2,2) 上验证候选 (A) 的弱命题，并判断其是否已有文献覆盖。
3. 研究 Grassmann 丛版本以撤去“一侧已全纯”。
4. 优先解决“已有环面拓扑”的任意秩问题。
5. 将方法移到有共振的 nil 拓扑模型，目标改为双 Lipschitz 共轭。
6. 最后集中处理一般系统的模型构造/全局齐性；这是当前规划中最大的缺口。

顺序可随反例、已有定理或非空性检验调整；不承诺较弱命题成立就自动解决一般情形。
