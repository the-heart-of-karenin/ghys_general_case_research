# 41 的加强：去掉保辛假设，并由正熵推出射影性

日期：2026-10-18。性质：完整的约化证明。原 41 的周期曲面论证保留；本记录补齐新的前提约化，不证明一般 Ghys 刚性。奇秩简单 Hodge 结构的等距群只有 ±I 是标准事实，不主张为新引理。

## 1. 加强后的准确陈述

**定理。** 设 X 为 K3^[2] 型 IHS 四维流形，ρ(X)=2，f∈Aut(X)，h_top(f)>0。不额外假设 X 射影，也不要求 f 保持全纯辛形式。则：

1. X 自动射影。
2. f* 在 T(X)_Q=NS(X)_Q^⊥ 上为 +I 或 −I；因此 f*Ω=±Ω，f² 保辛。
3. X 没有 f-周期的光滑紧复曲面，也没有周期曲线或周期除子。
4. 任意周期不可约曲面若存在，则必为奇异曲面，其光滑部分 Lagrangian，且奇点有限。

第 3、4 项由前两项和 41 得到。不把这称为 K3^[2] 型 Anosov 不存在性：正熵假设没有提供任何周期曲面的存在。

## 2. 简单性：不需要先假定 NS 为双曲格

令 V=H²(X,Q)，N=NS(X)_Q，q 为 BBF 型。只要 q|N 非退化，就有 V=N⊕T，T=N^⊥，而 T 没有非零有理 (1,1) 类。

**引理 1。** 在上述非退化前提下，T 是简单有理 Hodge 结构。

**证明。** 设 R⊂T 为有理 Hodge 子结构。如果 R 不含 Ω，由 h^{2,0}=1 及实结构，它是纯 (1,1)，故 R=0。

如果 R 含 Ω，它也含 barΩ。注意即使 X 非射影，这里仍可证明 q|R 非退化：rad(q|R)=R∩R^⊥ 是有理 Hodge 子结构，因为 q 是 Hodge 配对；q(Ω,barΩ)>0，使该根空间没有 (2,0)、(0,2) 部分。因此根空间纯 (1,1)，位于 T 中，只能为零。

于是 T=R⊕R^⊥ 是有理 Hodge 直和。后一个空间纯 (1,1)，仍只能为零，故 R=T。证毕。

这避免了把“射影时 T^{1,1} 负定”悄悄用于非射影情形。非射影负定 N 的情形中，T^{1,1} 实际并不负定，但根空间论证依然成立。NS 退化的情形不使用本引理，另见第四节。

## 3. 奇秩等距迫使平方保辛

**引理 2。** 若 (T,q) 是奇数维的简单有理 Hodge 结构，q 非退化，且 B 是有理 Hodge 等距，则 B=±I。

**证明。** 因为 B^{-1} 与 B^t 相似，B 的特征值多重集在 z↦z^{-1} 下不变。奇数维意味着至少有一个特征值 ε 满足 ε=ε^{-1}，即 ε=±1。

ker(B−εI) 是非零有理 Hodge 子结构，故由简单性等于 T。于是 B=εI。这里没有预设 B 有限阶，也没有用 Kronecker 定理去推断无限阶映射的整体阶数。证毕。

**推论。** 若 X 射影且 b₂(X)−ρ(X) 为奇数，则任意 f∈Aut(X) 在 T 上为 ±I，因而 f² 保辛。特别地，K3^[2] 型、ρ=2 时 dim T=23−2=21，取平方总是足够。

该奇秩 Hodge 事实也见 Huybrechts [39] 关于三次四维体 K3 范畴的论文：所保存作者稿 Proposition 3.11 的证明，PDF p.22，引用其 K3 讲义 Corollary 3.3.5；期刊版对应命题编号为 3.12。上文给出独立短证明，不要求读者借用范畴论内容。

## 4. 正熵、Picard 数二自动推出射影性

假设 X 非射影。由 Huybrechts 的射影性判据 [18] Theorem 2，N 没有正平方向量。由于 N⊂H^{1,1}(X,R)，而 H^{1,1} 上 q 的签名为 (1,20)，秩二 N 只有以下两个可能。

### 4.1 N 负定

引理 1 适用，T 简单且维数 21。因此引理 2 给出 f*|T=±I。

N_Z 是负定整数格，其整数等距群有限，所以 f*|N 的全部特征值也在单位圆。故 f*|H² 的全部特征值在单位圆。

对 K3^[2] 型，H⁴_Q=Sym²H²_Q、奇数次上同调为零，而 H⁶ 与 H² 的作用由 Poincaré 对偶互逆，H⁰、H⁸ 上为恒等。因此所有上同调谱半径都为 1，Gromov–Yomdin 公式给出 h_top(f)=0，矛盾。

这里不需要 Aut(X)→O(H²) 的忠实性；排除正熵只需谱半径结论。

### 4.2 N 负半定且退化

Lorentz 空间中全零平方子空间的维数至多为一，因此 rad N 是有理直线。取原始整数生成元 ℓ，有 f*ℓ=εℓ，ε=±1。

令 H=H^{1,1}(X,R)，q|H 的签名为 (1,20)。不变滤过

\[
0\subset\mathbb R\ell\subset\ell^\perp\subset H
\]

在中间商 ℓ^⊥/Rℓ 上诱导负定二次型，所以该商作用的全部特征值为单位模。首项的作用为 ε；由 q 配对，末商 H/ℓ^⊥ 上的作用为 ε^{-1}。故 H 上全部特征值在单位圆。

在正定平面 span_R(ReΩ,ImΩ) 上，f* 保 q 和复结构，所以是旋转，其特征值也在单位圆。因此 H² 上全部特征值在单位圆，沿用上一小节的上同调与熵论证，仍得 h_top(f)=0，矛盾。

两种非射影情形均已排除。因此 X 射影。证明没有要求 ℓ 半丰沛、存在 Lagrangian 纤维化或 SYZ 猜想。

## 5. 周期曲面的约化没有损失

现在 X 射影，第三节给出 F=f² 保辛。并且

\[
h_{\rm top}(F)=2h_{\rm top}(f)>0,
\qquad
\{\text{f-周期子簇}\}=\{\text{F-周期子簇}\}.
\]

最后一个等式只是：若 f^m(Y)=Y，则 F^m(Y)=Y；若 F^m(Y)=Y，则 f^{2m}(Y)=Y。

41 的全部前提因而适用于 F，且周期对象集合恰相同，得到第一节第 3、4 项。特别地，41 原有 k、e、χ 的算术结论完全不变。

也可以不换映射而直接核查 41：

- f*|T=εI，ε=±1，因此 Sym²T 上仍为恒等；N⊗T 上的特征值为 ελ、ελ^{-1}，均不为 1。
- 非 Lagrangian 曲面上 Ω 的限制是特征典范截面，特征值为 ±1；它的零除子仍被保持，足以产生同样的周期曲线矛盾。
- 周期 Lagrangian 类的一维压缩只用上述上同调不变部分与 αΩ=0，故也不变。

取平方的证明更短；直接核查则说明这里没有隐藏的符号误差。

## 6. 一般射影 IHS 上保辛也只是有限次迭代约化

补充一个不依赖奇秩的标准事实。射影 IHS 的 T_R 分成 q-正定的 Ω 实平面 P 与 q-负定的 T_R∩H^{1,1}。在 T_R 上定义

\[
g(v,w)=q(v_P,w_P)-q(v_{1,1},w_{1,1}).
\]

这是正定实内积。任意自同构的 Hodge 等距作用保持 g，也保持满秩格 T_Z。故其作用属于紧群 O(g) 与离散群 GL(T_Z) 的交，该交有限。于是每个自同构都有保辛迭代，且整个 Aut(X) 在 T 上的像有限。

这说明对射影 IHS 的、在有限次迭代下不变的问题，单独撤掉保辛假设通常不是实质难点。本轮的特殊加强是 ρ=2、K3^[2] 时可统一取平方，且正熵还迫使射影性。

不要把这推广成“任意非射影 IHS 自同构也有保辛迭代”：第四节的证明明确用了秩二和奇秩 T，非射影正熵的一般情形不在本结论中。

## 7. 进一步检验与准确边界

- 新增的反辛正熵分支并非仅形式上可能。44 给出显式秩二格、整数 Hodge 等距，并用墙与 Torelli 定理把它实现为实际射影 K3^[2] 自同构。45 更进一步证明：带有任意反辛正熵自同构的秩二 X，都没有任何全纯 Anosov 自同构。
- ρ=2 仍是实质前提。自然 Hilbert 平方上从正熵 K3 自同构诱导的映射具有更高 Picard 数和实际周期曲面；已有 36 Example 2.24 可作检验。
- 双有理自映射不能直接代替处处正则自同构：即使其二阶上同调也满足符号约束，41 中曲面限制必须是光滑射影曲面的自同构，这一步不能省去。
- 只剩孤立奇点 Lagrangian 周期曲面的缺口未缩小；42 的正规局部锥面仍适用。
- 原 Ghys 目标所需的横向正则性、熵等号或周期几何对象存在性仍未得到。45 排除的是明确的反辛正熵分支；剩余保辛分支不因此自动解决。
