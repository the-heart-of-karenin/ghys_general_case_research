# 单张快形式的 proper 全纯约化：紧致四维 Anosov 族、恒定周期与稠密底平移

日期：2026-10-19。性质：98 的准确非退化快位移所给的全局结构定理。没有假设第二张形式或消去平方根 cocycle；没有把非离散周期商当作复流形。

## 1. 构造及结论

沿用 98 的取逆约定：f*α=r⁻¹α，fφ_zf⁻¹=φ_rz，r=λ²。原基本群为

\[
\Gamma=\{(r_0,s,t):r_0,s,t\in R\},\qquad
(r_0,s,t)(r'_0,s',t')
=(r_0+r'_0,s+s',t+t'+\bar r_0s'),
\tag{1.1}
\]

R=ℤ[i,√3]。为避免 r 与 r₀ 混淆，r 只表示实伸缩 λ²，r₀ 表示格参数。取正规子群 Γ₀={r₀=0}≅Z⁸，相应中间覆盖为

\[
\widehat X=\widetilde X/\Gamma_0\longrightarrow X,
\quad\operatorname{Deck}(\widehat X/X)=R.
\tag{1.2}
\]

**定理。**

1. φ 的 C 作用在 X̂ 上自由且 proper，商 Q=X̂/C 为复五维流形，π:X̂→Q 为全纯主加法群 C 丛。
2. α 的发展映射下降为一个 proper 全纯 submersion

   \[
   q:Q\longrightarrow\mathbb C_\zeta,
   \tag{1.3}
   \]

   各纤维 Y_ζ 为紧致、同胚 T⁸ 的复四维流形，带相对闭全纯辛形式 σ_ζ。
3. f 下降为覆盖 ζ↦r⁻¹ζ 的全纯自同构 G。Y₀ 上的 g=G|Y₀ 是真实保辛 Anosov，并经标记共轭于只含 λ、λ⁻¹ 的半单环面自同构。
4. q 的辛周期 [σ_ζ] 在 Gauss–Manin 标记下恒定；全部 Dolbeault 数 h^{p,k}(Y_ζ) 也恒定。
5. R 在 Q 上作用，覆盖 C 上一个稠密且无核的平移群；在纤维整数一阶同调上的运输为原指定 unipotent 剪切 L_{r₀}。

第 4 项不等于复结构恒定，也不直接给第二张形式。100 将剩余接口缩为这个实际主 C 丛的一个 Dolbeault 类。

## 2. 不经过稠密周期商的 proper C 作用

74 给发展映射 Φ=LH，dΦ=α。因为 α 属一张快特征形式，L 只依赖快 primary 的一个实二维特征块，且在该块上为实线性同构到 C。记这个收缩快坐标为 ζ；另一扩张快实二维坐标记 a。

在模型覆盖 Γ₀\G 上，快坐标 (a,ζ) 均为单值实坐标，且

\[
\Gamma_0\backslash G\simeq\mathbb R_a^2\times
\mathbb R_\zeta^2\times\mathbb T^8_{s,t}.
\tag{2.1}
\]

98 给 φ_z 在 H 坐标下恰将 a 改为 a+b(z)，ζ 不变；其余方向允许临界 c_z。b:C_R→R_a² 为同构，所以作用自由。

若 p_j、φ_{z_j}(p_j) 都留在 X̂ 的紧集内，则 a(p_j)、a(φ_zjp_j) 有界，故 b(z_j) 有界，z_j 有界。这正给 proper 性。它使用非退化快位移，没有要求 c_z=0。

每条轨道恰交拓扑截面 {a=0} 一点：取 z=−b⁻¹a 即可。截面选取连续，因此

\[
Q\simeq_{\rm homeo}\mathbb R_\zeta^2\times\mathbb T^8.
\tag{2.2}
\]

V 在覆盖上处处非零。全纯 flow box 给局部复五维横截片；proper 性允许缩小这些片而避免非局部轨道的额外识别，且给 Hausdorff 商。片之间的转移由全纯流和全纯隐函数定理给出，故 Q 是复流形，π 为全纯主 C 丛。这里的商发生在覆盖上，不是 C/稠密周期群。

## 3. 真正的紧致复四维辛纤维

Φ 在 X̂ 上单值全纯，ι_VΩ=dΦ，且 VΦ=0。故 Φ=qπ，其中 q 全纯。α 处处非零，dπ 的核为 V，遂使 q 为 submersion。

(2.2) 中 q 正是 ζ 坐标，因而 proper，纤维紧致并同胚于 T⁸。对 Φ⁻¹(ζ)，Ω 限制的核恰为 V；它对 C 作用不变，故下降为 Y_ζ 上的非退化闭全纯二形式 σ_ζ。局部全纯 slice 还给一个全纯相对二形式 σ∈H⁰(Q,Ω²_{Q/C})。

没有将“稳定 K 理论中的候选丛”视为实际纤维；这里每张 Y_ζ 都是 proper 全纯商的真实紧致复流形。

## 4. 约化返回 g 的 Anosov 性不能省略证明

f 的准确提升将 C 轨道送到 C 轨道，并满足 Φf=r⁻¹Φ，因此下降为 G，保各纤维的辛形式。Y₀ 为 G 固定纤维。

在 Φ⁻¹(0) 中取拓扑截面

\[
K_0=H^{-1}\{a=0,\zeta=0\}.
\tag{4.1}
\]

它紧致，π|K₀:K₀→Y₀ 为同胚，且 f̂K₀=K₀，因为模型 F 保快坐标零集。这提供一个**紧致不变连续截面**，不需要全纯截面。

因 f*α=r⁻¹α，71 给 α|E^u=0。故在 Φ⁻¹(0) 的实际切丛中

\[
T\Phi^{-1}(0)=E^u\oplus(E^s\cap\ker\alpha),
\quad V\subset E^u,
\tag{4.2}
\]

后一个稳定交秩二，E^u/V 秩二。原 f 的一致收缩传给稳定交，原逆迭代的一致收缩传给不稳定 quotient。沿紧致 K₀，Dπ 识别

\[
(T\Phi^{-1}(0)/\langle V\rangle)|_{K_0}
\simeq TY_0
\tag{4.3}
\]

的范数及逆范数都有统一界。K₀ 真正不变，因此迭代比较中不会引入逃向无穷的截面或不断累积的 C 平移导数。于是 Dg 获得真实的一致双曲分裂，g 为 Anosov。

把 K₀ 在 H 下的 (s,t) 标记传给 Y₀，得到 Hg=AH，A 为原模型核上的半单整数矩阵，只含 λ、λ⁻¹。不是对任意环面型子商免费套用 Franks–Manning。

## 5. 周期恒定来自主 C 丛的光滑平凡性

加法群 C 可缩，且光滑函数层是 fine 层，故主 C 丛 π:X̂→Q 有全局光滑截面 s。此处不声称它全纯。令

\[
\eta=s^*\Omega\in A^2(Q,\mathbb C),\qquad d\eta=0.
\tag{5.1}
\]

沿每张 q 纤维，η|Y_ζ=σ_ζ。原因是两个截面相差一个点依赖的 C 平移，其导数引入的额外 V 分量与纤维切向的 Ω 配对为 dΦ=0；限制不依赖截面。

所以整个相对辛形式族来自同一个闭光滑二形式。对任意 Gauss–Manin 运输的二维循环，用 Stokes 定理即得

\[
\boxed{[\sigma_\zeta]\text{ 恒定。}}
\tag{5.2}
\]

这比仅由正规化推出“周期至多仿射变化”更强。加法群没有非零拓扑 Chern 类，不能把紧群约化中可能出现的线性周期斜率擅自保留到这里。

η 通常不全纯；也没有证明等周期蕴含全纯平凡。非 Kähler 环境下，所需的局部 Torelli/原函数相容性不能省略。

## 6. 稠密 deck 平移与全部 Hodge 数恒定

覆盖 X̂→X 的 deck R 与 φ 交换，故下降为 Q 上的交换全纯作用 γ_{r₀}。它满足

\[
q\gamma_{r_0}=q+\ell(r_0),
\qquad \ell:R\longrightarrow\mathbb C.
\tag{6.1}
\]

ℓ 是选定快嵌入 R→C 后复合一个实线性同构，因此无核，像稠密。γ 给 Y_ζ→Y_{ζ+ℓ(r₀)} 的实际双全纯保辛映射。其在 π₁=Γ₀ 上的作用，由 deck 共轭准确为

\[
L_{r_0}(s,t)=(s,t+\bar r_0s).
\tag{6.2}
\]

对于 proper 全纯 submersion q，相对 Ω^p 为局部自由、q-flat，Grauert 上半连续性给 h^{p,k}(Y_ζ) 上半连续。任意超水平集 {h^{p,k}≥j} 闭，并受稠密平移群保持；非空时其闭性使它等于整个 C。因此

\[
\boxed{h^{p,k}(Y_\zeta)\text{ 对全部 }\zeta\text{ 恒定。}}
\tag{6.3}
\]

尤其 E=R¹q_*O_Q 为全纯向量丛，且其纤维准确为 H¹(Y_ζ,O)。这是 Grauert 在恒定维数下的 base-change 结论，不要求 Y_ζ Kähler。

## 7. 与 76 的差别及停止点

76 从两张形式得到 C²×Y 的实际平坦悬挂，R 的每个元素都在**同一个** Y 上作用。这里则只得

\[
\widehat X\xrightarrow{\ \mathbb C\ }Q\xrightarrow q\mathbb C,
\]

deck 元素把 Y₀ 送到不同的 Y_ℓ。ℓ 无核，除恒等外没有一张现成的同纤维单值 ρ_r 可直接使用。因此不能把 82–96 的固定纤维公共线证明原样搬来。

另一方面，本篇的全局 proper 约化、紧致 Anosov 纤维、恒定辛周期和恒定 Hodge 数均已从原始假设取得，不是额外条件。100 将“如何补上第二张形式”进一步定位为主 C 丛在 Y₀ 上的一个具体 Dolbeault 类能否消失。
